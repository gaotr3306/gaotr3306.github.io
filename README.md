# Tianrun Gao — Academic Website

Static multi-page academic website designed for GitHub Pages.

## Structure
- `index.html` — homepage
- `research.html` — research page
- `publications.html` — selected publications
- `academic.html` — education, awards, teaching
- `contact.html` — contact information
- `style.css` — shared styling
- `assets/avatar.jpg` — add your portrait here
- `cv/CV_Tianrun_Gao.pdf` — add your CV here

## Publish with GitHub Pages
1. Create a repository named `gaotr3306.github.io` (or use any repository with GitHub Pages enabled).
2. Upload the files in this folder to the repository root.
3. If using `gaotr3306.github.io`, the site should publish from the `main` branch automatically or via Settings → Pages.
4. Add `assets/avatar.jpg` and `cv/CV_Tianrun_Gao.pdf`.

No JavaScript is required. Navigation opens separate HTML pages instead of scrolling to anchors on one long page.
